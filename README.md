# Machine Learning Fundamentals

**Understanding Machine Learning from the ground up — through mathematics, code, experiments, and continuous learning.**

This repository documents my journey of learning Machine Learning (ML), from foundational concepts and mathematical intuition to implementing algorithms and experimenting with real-world datasets.

Rather than treating ML as a collection of libraries and APIs, my goal is to understand **how algorithms work, why they work, and when to use them.**

The repository will evolve alongside my learning, serving as a collection of notes, implementations, experiments, and practical insights.

---

## 🧠 My Approach to Learning

For each major concept or algorithm, I aim to document:

1. **Intuition:** What problem does it solve, and why do we need it?
2. **Mathematics:** The equations, assumptions, and derivations behind it.
3. **Implementation:** A Python or NumPy implementation to understand the mechanics.
4. **Library implementation:** How the algorithm can be applied using libraries such as scikit-learn.
5. **Experiments:** Test the algorithm on data and observe its behavior.
6. **Evaluation:** Analyze performance, limitations, and failure cases.
7. **Key takeaways:** Summarize what I learned and what questions remain.

The objective is not just to make a model work, but to understand what happens beneath the API.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/ml-fundamentals.git
cd ml-fundamentals
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On Linux or macOS:

```bash
source .venv/bin/activate
```

On Windows:

```powershell
.venv\Scripts\activate
```

Install dependencies when `requirements.txt` is available:

```bash
pip install -r requirements.txt
```
